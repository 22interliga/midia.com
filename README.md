# Interliga Last Mile

Protótipo funcional do painel de operação Last Mile, feito em HTML, CSS e JavaScript puro para funcionar diretamente no GitHub Pages.

## Recursos já incluídos

- Dashboard operacional
- Pedidos com cadastro e busca
- Despacho manual demonstrativo e despacho automático
- Roteirização visual
- Motoristas
- Veículos: Moto e Inter Car
- Clientes
- Precificação e faixas de km
- Financeiro
- Relatórios e KPIs
- Layout responsivo para celular
- Dados persistidos no `localStorage`
- PWA básica / service worker

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve.

O GitHub publicará o sistema como um site.

## Próxima etapa recomendada

Este pacote é o front-end funcional inicial. Para uso real em produção, o próximo passo é conectar autenticação, banco de dados, API de mapas/rotas, GPS em tempo real, upload de comprovantes e backend.
