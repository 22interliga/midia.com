# Last Mile • Operação DS v4
Projeto independente para operação logística Last Mile/DS.

## Publicar no GitHub Pages
Envie os arquivos soltos para a raiz do repositório e configure Settings > Pages > Deploy from a branch > main > /(root).

## Importação CSV
Cabeçalhos aceitos: waybill;referencia;cliente;destinatario;telefone;endereco;cidade;prazo;volumes

Os dados desta versão são armazenados no navegador (localStorage). Para produção, conectar a backend/banco de dados.
